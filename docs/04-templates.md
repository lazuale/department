## 1. Название работы

```text
<результат> — <основание или период>
```

Примеры:

- `Обработать основание №123`;
- `Провести сверку — 2026-08`;
- `Получить документ — тема X`.

Не использовать: `Срочно`, `Посмотреть`, `Письмо`, `Важно`, `RE:`.

## 2. Обычная работа

```text
Название: <понятный результат>
Тип: Работа
Категория: <если используется>
Исполнитель / групповая очередь: <человек / группа>
Срок: <внешний или внутренний срок процесса>
Приоритет: Обычный / Критичный
```

Описание — только если без него непонятен результат:

```text
Основание: <что запустило работу>
Нужно получить: <результат>
Особые условия: <если есть>
```

## 3. Запрос документа или материала

Использовать только по критериям раздела 13 [модели управления](01-methodology.md#13-запрос-документа-или-материала).

```text
Название: Получить <документ/материал> — <тема>
Тип: Запрос
Категория: <если используется>
Исполнитель: <после отправки — конкретный человек>
Срок: <дата получения>

Нужно получить: <точно что>
Кому направлен запрос: <адресат>
Связано с: #<ID, если есть>
```

## 4. Ожидание

```text
Ожидание: <что блокирует продолжение>.
Действие: <что сделано и когда>.
Связанная карточка: #<ID, если есть>.
После снятия блокировки: <следующий шаг>.
```

Не писать только `ждём`, `нет ответа`, `уточняется`, `в процессе`.

## 5. Идея улучшения

```text
Название: <проблема или предложение>
Наблюдение: <что происходит>
Факты: <карточки или показатели>
Потеря: <время / качество / срок / ручной труд / лишняя передача>
```

## 6. Карточка процесса

См. [05 — Описание процессов](05-processes.md#1-карточка-процесса).

## 7. Локальные правила

```text
Контрольное время входящих, если используется:
<время или правило>

Категории, если используются:
<категория> — <для чего нужна>

Групповые очереди, если используются:
<группа> — <самоназначение / контролируемое назначение>

Внутренние сроки, если нужны:
<процесс> — <срок>

Горизонт периодических работ, если есть периодические работы:
<процесс> — <горизонт>

Контроль качества, если используется:
<периодичность и объём>

Дата изменения:
<дата>
```
