# Governance обучающей wiki Odoo 19

Этот каталог содержит правила, которые управляют всей wiki. Они не являются учебными уроками и не должны дублировать содержание уроков.

## Что здесь хранится

- [Метод курса](method.md) — порядок изучения и правила качества;
- [Политика источников](source-policy.md) — какие официальные источники использовать и какой источник имеет приоритет;
- [Владение понятиями](concept-ownership.md) — единственный владелец каждого фундаментального понятия;
- [Реестр редакций](edition-ledger.md) — доказанный статус Community / Enterprise / не установлен;
- [Глоссарий](glossary.md) — короткий индекс терминов со ссылками на уроки-владельцы.

## Базовое правило

```text
Governance определяет правила
        ↓
Owner-урок определяет понятие
        ↓
Последующие уроки используют понятие
```

Governance не должен превращаться во вторую энциклопедию Odoo.
