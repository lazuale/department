# Правила обучающей wiki Odoo 19

Этот каталог содержит правила, которые управляют всей wiki. Это не учебные уроки, и они не должны дублировать содержание уроков-владельцев.

## Что здесь хранится

- [Метод курса](method.md) — область курса, стабильные ID и правила качества;
- [Канонический граф предпосылок](course-dag.md) — единственный нормативный граф зависимостей уроков;
- [Политика источников](source-policy.md) — официальные источники, их приоритет и строгая трассировка `[ODOO][S#]`;
- [Владение понятиями](concept-ownership.md) — канонические владельцы и владельцы отдельных аспектов;
- [Карта покрытия](coverage-map.md) — раздел официальной документации → владелец/область → статус;
- [Реестр редакций](edition-ledger.md) — отдельно общие факты о Community/Enterprise и доступность конкретных функций/модулей;
- [Глоссарий](glossary.md) — короткий индекс терминов;
- [Baseline B1](baseline.md) — замороженный фундамент и правила его изменения.

## Базовая модель

```text
Политика источников
      ↓
Карта покрытия ─────────► не даёт потерять тему
      ↓
Владение понятиями ─────► не даёт определить понятие дважды
      ↓
Граф курса ─────────────► не даёт использовать понятие раньше предпосылки
      ↓
Урок
      ↓
Реестр редакций ────────► не даёт угадывать Community/Enterprise
```

## Состояние baseline

```text
Baseline: B1
Дата:     2026-08-13
Статус:   frozen foundation
```

После B1 фундамент не перестраивается только из-за стилистических предпочтений или появления очередного урока. Допустимые основания для структурного изменения перечислены в `baseline.md`.

Правила курса не должны превращаться во вторую энциклопедию Odoo.
